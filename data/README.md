# data

Every non-code input of the repository.

| Path | What |
|------|------|
| `model/` | The component model and the generators' inputs: `components.json` (creator docs), `mappings.json`, `coverage.md`, `bds-feedback.json`, `transforms.json`, `fixtures.json`, `api.json`, `conformance-known.txt`, `wire-gaps.txt`, `ATTRIBUTION.md`; `names.json` and `constants-history.json` (vanilla constants) |
| `fallbacks/` | Hand-curated fallbacks for blocks and items missing in older bundled versions |
| `bds/<bds version>/` | What one BDS build gave: `addon/` (capture of the capture add-on), `vanilla/`, `creative-*/` (captures of the creative probes), `spec/` (capture of the spec add-on, input of `infer`), `dump.json.gz` (Script API dump, the baseline of `update`), `experiments.json`, `report.md` (an update report) |
| `bds/WIRE-NOTES.md`, `bds/CREATIVE-ORDER.md` | What BDS sends, and how it orders custom content in the creative inventory |
| `addons/` | The packs run on BDS: `capture` (every component; generated by `addon --kind capture`, plus the committed `content-log.txt`), `creative` (generated by `addon --kind creative`), `dump` (hand-written Script API dump pack) |

Generated: `addons/capture` and `addons/creative` (never edit; `FixedAddonsTest` checks them), `model/mappings.json`,
`model/coverage.md`, `model/bds-feedback.json`.
